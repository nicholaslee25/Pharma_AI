## Overview
No FDA drug label exists — HALLS Defense is a **dietary supplement** (vitamin C drops), not an FDA-approved OTC drug. Manufacturer Supplement Facts confirm: standard formula delivers 135mg vitamin C per 2-drop serving (as sodium ascorbate + ascorbic acid, ~150% DV); sugar-free formula is similar with isomalt as the base. This is a new ingredient link — the prior page had no pointer at all — to [[vitamin-c]]. Not the same product as regular HALLS cough drops (menthol-based, filed separately under Topical Cough Suppressants Lozenges in this database).

## Pros
- Convenient drop format for on-the-go vitamin C dosing
- Sugar-free variant available for those managing sugar intake

## Cons
- No brand-specific clinical trial exists for HALLS Defense; see [[vitamin-c]] for the actual ingredient-level evidence, which shows only modest (~8% adult) reduction in cold duration from regular supplementation and no meaningful prevention effect in the general population
- 135mg per serving is a small fraction of typical "cold remedy" high-dose vitamin C products (e.g. Emergen-C's 1,000mg) — a real dose difference within this database worth noting since both are filed under similar categories despite the large potency gap
- Contains soy (standard formula) — relevant allergy note not on a typical vitamin label a consumer might expect to double check

## Use Cases
Light vitamin C supplementation; marketed alongside cold season but not FDA-labeled to treat or prevent colds.

## Allergies / Warnings
Contains soy lecithin. No FDA-mandated drug warnings (dietary supplement).

## Symptoms Treated
Not FDA-labeled to treat symptoms — general nutritional/immune support marketing only.
