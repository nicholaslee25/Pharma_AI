## Overview
Pamprin Multi-Symptom Maximum Strength is confirmed via DailyMed as acetaminophen 500mg + pamabrom 25mg + pyrilamine maleate 15mg per caplet — the same three-role structure as [[Midol]] (analgesic + diuretic + antihistamine) but using pamabrom instead of caffeine as the diuretic component. Pamabrom is a mild diuretic (a xanthine derivative structurally related to caffeine/theophylline) specifically marketed for premenstrual water-weight/bloating relief; this database did not independently locate a dedicated pamabrom efficacy RCT in this pass, the same evidence-gap pattern already flagged for Midol's caffeine component. A separate "Pamprin Cramp Formula" (ibuprofen-based, per real-world market identity) is also sold under the Pamprin name — not independently verified against a label in this pass, but consistent with this database's recurring one-brand-multiple-formulations pattern.

## Pros
- Acetaminophen component carries the same well-established analgesic/antipyretic evidence as every other acetaminophen product in this database (see [[acetaminophen]])
- Caffeine-free diuretic (pamabrom) is a real, meaningful differentiator for caffeine-sensitive users choosing between Pamprin and Midol Complete (which uses caffeine)
- Directly targets the same symptom cluster (cramps, headache, backache, bloating, water-weight gain) as its main competitor

## Cons
- **No dedicated Pamprin-brand RCT for the triple-combination formula was located in this pass** — same gap already noted for Midol
- Standard acetaminophen hepatotoxicity warning applies: severe liver damage risk above 8 caplets/24h or when combined with other acetaminophen-containing products
- Pyrilamine's first-generation-antihistamine anticholinergic side-effect profile applies (drowsiness, dry mouth) — same class caution as Midol's pyrilamine component
- If a "Pamprin Cramp Formula" (ibuprofen) SKU exists alongside this acetaminophen-based Multi-Symptom product under the same brand name, the same brand-name-does-not-specify-active-ingredient caution already flagged for Midol applies here too — not independently confirmed against a label in this pass, so flagged as a real possibility rather than a fully verified finding

## Use Cases
Temporary relief of menstrual symptoms: cramps, headache, backache, irritability, bloating, muscle aches, water-weight gain (per label).

## Allergies / Warnings
Standard acetaminophen liver-injury warning (do not exceed 8 caplets/24h or combine with other acetaminophen products). Pyrilamine carries standard first-generation-antihistamine cautions (avoid with alcohol/sedatives; caution in glaucoma, breathing problems, enlarged prostate).
