**Last updated:** 2026-08-24

---

The project originally started from two ChatGPT-compiled evidence dossiers. As of 2026-08-24, both were deleted — their AI-written prose/interpretation was redundant weight once real primary sourcing began (StatPearls, FDA labels, Cochrane, PubMed abstracts — see the [[ibuprofen]] pilot for the pattern). All that had lasting value was the list of real studies they pointed at, so that list was extracted into `raw/pharmacy-research/chatgpt-dossier-citation-index.md` and kept as a checklist for the primary-sourcing rebuild pass.

Every citation in that index is an **unverified pointer** — something to go check and pull directly, not an established fact. Two entries were flagged during extraction as suspicious/worth double-checking before trusting them (PMIDs 42014704 and 42464966 — both unusually recent for a ChatGPT knowledge cutoff).

Only [[ibuprofen]] has been rebuilt from real primary sources so far. The other 76 `ingredients/*.md` pages still contain the original AI-compiled content and point at this citation index as their "sources to go verify" list until each gets rebuilt the same way.
