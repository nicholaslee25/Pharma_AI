## Note
This is an early version (2000) of the same Cochrane review series that culminated in the 2015 Mathie/Frye/Fisher update (see separate raw file, `cochrane-mathie-2015.md`) — itself following on from Vickers & Smith's original 1998 review. This vault's ingredient page uses the 2015 update as the current/authoritative version of this review series, per standard practice of citing the most recent update rather than superseded earlier versions. This file exists only to document that the citation-index's original PMID 10796675 pointer was checked and found to be a real, correctly-attributed PMID for an earlier version of the same review, not a phantom citation.
